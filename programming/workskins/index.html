AO3 Workskin Projects and Tutorials

pumpkinPatchier

Summary:

You may have noticed that this page looks a bit different than the others. There is no need for concern, this is the intended style. These are the projects that I created for use with Archive of Our Own (AO3). It's a popular writing website meant for sharing fanfiction with limited support for HTML and CSS through workskins.

Don't be fooled by all the bells and whistles though. We are still in my portfolio, but since these projects originally existed on AO3, it makes sense to host them on a webpage that looks like AO3.

One of my hobbies is trying to create code that can run in AO3, since the limitations can lead to interesting challenges and creative solutions. Since you are barred from using any sort of scripting, interactivity is instead done through on-hover effects and drop-down menus. It sounds quite limiting, but that just makes it all-the-more impressive when you create choose-your-own-adventure stories with branching plotlines.

Funny enough, this website is what taught me CSS and HTML and started my interest in web development. And since I am indebted to the tutorials on AO3 that taught me how to code, when I finally became confident enough to create my own new ideas, I was excited to make my first tutorial to give back to the community that taught me what I know.

I was personally very touched to have so many people comment on my work and tell me that they were blown away by the visual effects on my first tutorial for making what I called "Stylized CSS Card Links".
