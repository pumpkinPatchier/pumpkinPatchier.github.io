Interactive Cooking Simulation (GDScript)

Ever since I was young, I've always been drawn to Virtual Pet and Cooking games and was astounded to find that the selection for "Virtual Pet Cooking Games" was next to none. I'm fascinated by games that implement a "throw anything in the pot and anything comes out" sort of cooking algorithm.

Easy enough to wish for, but much more difficult to implement effectively. What sounds like the whim of a gamer soon becomes an elaborate algorithm, involving vector aggregation, weighted biases, procedural generation alongside manual overrides, and much more!

This is a data-based video game that I programmed in Godot. It uses no libraries, no shared assets, no audio; everything that you see here was programmed by myself using my own skills and what the Godot engine provided me with.

To summarize, this game implements:

  • Rule-based crafting system modeling relationships and constraints (logic and problem-solving).
  • Procedurally generating object properties from recursively traversing tree-structured nodes.
  • Demonstrated full-cycle game development with programming, art, shaders, UI, and audio design.
